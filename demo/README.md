# 中国移动客户体验分析平台 - 功能演示文档

## 项目概述

本项目演示一套完整的客户体验分析平台，包含三大核心功能：大规模合成用户画像生成、交互式任务模拟、以及客户旅程可视化与断点分析。全部使用 Python + Playwright + Matplotlib + ffmpeg 实现。

---

```

├── run_demo.py                   # 总控脚本，顺序运行三个功能点

├── record_and_run.ps1            # 自动录制+运行 (一键完成)

├── feature2_simulate.py          # 功能点2: Playwright 自动化模拟

    ├── synthetic_users.csv       # 生成的800个用户画像
```

## 功能点1: 大规模合成用户生成 (2分)

### 功能描述

演示如何自动生成成百上千个具有不同用户画像(Persona)的用户数据。系统能基于预设的用户画像模板，按照统计分布规律批量生成大规模的合成用户数据集。

### 实现细节

**技术方案:**
- 纯 Python 实现，无需外部 LLM API 依赖
- 基于统计学分布(高斯分布、指数分布)生成逼真的用户属性
- 使用加权随机选择算法按画像权重分配用户

**6种用户画像模板:**

| 画像类型 | 年龄范围 | ARPU区间 | 典型行为特征 |
|---------|---------|---------|------------|
| 商务精英 | 28-55岁 | ¥128-588 | 高频通话、国际漫游、企业VPN |
| 潮流青年 | 16-28岁 | ¥38-128 | 大流量、视频会员、游戏加速 |
| 家庭用户 | 30-50岁 | ¥88-238 | 共享套餐、宽带融合、智能家居 |
| 银发一族 | 55-80岁 | ¥18-58 | 语音畅聊、健康监测、防诈提醒 |
| 学生群体 | 12-22岁 | ¥18-58 | 校园流量包、学习APP免流、夜间流量 |
| 蓝领工人 | 22-50岁 | ¥38-98 | 语音优惠、视频通话、务工套餐 |

**每个用户包含16个属性字段:**
- 基础信息: ID、画像类型、性别、年龄、省份、城市
- 业务属性: 在网月数、ARPU、流量使用量、通话时长
- 偏好信息: 当前套餐、设备型号、偏好渠道、兴趣功能
- 体验指标: 满意度评级、流失风险等级、交互次数、最近交互天数

**生成数据示例 (来自 synthetic_users.csv):**

| user_id | persona_type | gender | age | province | arpu_yuan | data_usage_gb | satisfaction | churn_risk |

| CM000001 | 潮流青年 | 女 | 22 | 广东 | 89.50 | 45.2 | 满意 | 中低风险 |

**输出文件:**
- `output/synthetic_users.csv` - 800个合成用户完整数据 (UTF-8 BOM编码，Excel可直接打开)

**运行方式:**
```bash

```

**运行效果:**
程序执行时会实时显示生成进度条，完成后输出详细的统计分析，包括：用户画像分布、性别分布、核心指标均值、满意度分布、流失风险分布、渠道偏好分布、ARPU分档等。

## 功能点2: 交互式任务模拟 (2分)

### 功能描述

展示模拟用户如何在网页/APP/线上营业厅执行点击、搜索、多页面跳转等真实操作，完成在中国移动APP上针对咨询移动产品资费的交互。

### 实现细节

**技术方案:**
- Flask 构建模拟中国移动 APP 的 Web 应用 (5个完整页面)
- Playwright 驱动 Chromium 浏览器执行自动化操作
- 模拟真实手机端用户行为：viewport为420x850，使用移动端User-Agent
- 完整记录每一步操作的时间和事件类型到JSONL日志

**Mock APP 页面结构:**

| 页面路由 | 功能 | 对应真实APP页面 |
|---------|------|--------------|
| `/` | 首页 (含余额、流量、推荐套餐、导航菜单) | 中国移动APP首页 |
| `/products` | 产品中心 (5款套餐列表、分类Tab) | 套餐办理页面 |
| `/product/<id>` | 产品详情 (套餐详情+立即办理按钮) | 套餐详情页 |
| `/search?q=xxx` | 搜索页面 (含搜索框+热门标签+搜索结果) | 搜索功能 |
| `/my-account` | 我的账户 (订单列表+常用服务) | 个人中心 |
| `/support` | 在线客服 (FAQ+聊天模拟) | 客服咨询页面 |

**模拟的用户操作旅程 (8个步骤):**

```
步骤1: 用户打开APP，浏览首页
  ↓ 看到余额¥126.50、已用流量12.5GB、推荐套餐
步骤2: 点击搜索栏, 输入"移动产品资费"
  ↓ 触发搜索行为
步骤3: 查看搜索结果
  ↓ 看到移动产品资费大全、5G套餐、5G终端优惠等
步骤4: 点击"移动产品资费大全"进入产品中心
  ↓ 浏览全部套餐资费列表 (5款套餐)
步骤5: 点击"5G智享套餐"查看详情
  ↓ 查看套餐详情：30GB/500分钟/¥128每月
步骤6: 点击"立即办理"，提交订单
  ↓ 订单提交成功，生成订单号 ✅ (转化)
步骤7: 进入"我的"查看个人账户
  ↓ 查看在网月数、会员等级、积分
步骤8: 进入"在线客服"咨询移动产品资费
  ↓ 发送问题，智能客服回复
```

**输出文件:**
- `output/screenshots/` - 12张操作过程截图 (PNG格式)
- `output/interaction_log.jsonl` - 完整交互日志 (包含时间戳、事件类型、页面URL等)

**运行方式:**
```bash

python demo/feature2_app/mock_app.py

# 终端2: 运行Playwright自动化模拟
python demo/feature2_simulate.py
```

**运行效果:**
Playwright 会自动打开 Chromium 浏览器窗口 (移动端视口尺寸)，用户可以直观地看到模拟用户一步步的操作过程：浏览、点击、搜索、输入文字、页面跳转、按钮点击等完整交互。

## 功能点3: 旅程可视化与断点分析 (2分)

### 功能描述

系统自动生成客户旅程地图，直观展示每个阶段的触点、用户行为，并利用分析工具快速识别出体验的薄弱环节和高流失点。

### 实现细节

**技术方案:**
- Matplotlib 生成4张专业级可视化图表
- 基于模拟数据的旅程分析和断点识别
- 输出结构化的AI分析报告文本

**生成的可视化图表:**

#### 图表1: 客户旅程全景地图 (journey_map_overview.png)
- 7个旅程阶段横向排列: 认知发现 → 信息搜索 → 比较评估 → 购买办理 → 使用体验 → 客服咨询 → 续费/流失
- 每个阶段展示4个触点的气泡图 (气泡大小=访问量, 颜色=满意度)
- 红/橙/绿三色标识满意度等级
- 阶段背景色标识该阶段整体满意度水平

#### 图表2: 转化漏斗分析 (funnel_analysis.png)
- 从1000人认知到140人续费的完整漏斗
- 每阶段标注流失率百分比
- 红/橙/绿三色标识高/中/低风险阶段

#### 图表3: 薄弱环节分析 (pain_point_analysis.png)
- 4个子图:
  - 各阶段关键流失率柱状图
  - 痛点影响矩阵 (流失率 × 影响程度)
  - 各阶段满意度趋势对比 (综合 vs 数字渠道 vs 线下渠道)
  - 改进建议优先级排序 (Top 5)

#### 图表4: 流失预测仪表盘 (churn_prediction.png)
- 用户流失风险构成饼图 (5级风险)
- 月度流失趋势预测折线图 (含置信区间)

**AI断点分析报告摘要:**

```
关键发现:
1. 【续费/流失】流失率最高 (50.0%) — 竞品携号转网流程简化
   → 建议: 建立高价值用户预警系统，提前30天主动关怀

2. 【比较评估】35.4%在对比阶段放弃 — 套餐展示不直观
   → 建议: 引入AI智能推荐，一键对比核心差异

3. 【购买办理】33.3%办理途中放弃 — 表单填写繁琐
   → 建议: 优化至3步内完成，支持人脸识别快速认证

4. 【信息搜索】35.0%未找到有效信息 — 搜索匹配精度不足
   → 建议: 升级NLP语义搜索，增加智能导航

5. 【客服咨询】智能客服一次解决率偏低
   → 建议: 扩展知识库，引入大模型提供更精准回复
```

**输出文件:**
- `output/journey_map_overview.png` - 旅程全景地图
- `output/funnel_analysis.png` - 转化漏斗分析
- `output/pain_point_analysis.png` - 薄弱环节与断点分析
- `output/churn_prediction.png` - 流失预测仪表盘

**运行方式:**
```bash
python demo/feature3_journey.py
```

**运行效果:**
程序会依次显示4张可视化图表 (每张3秒自动切换)，同时在控制台打印详细的AI分析报告文本。

## 视频录制说明

### 方式一: 自动录制 (推荐)

使用 PowerShell 脚本一键完成录制+演示:

```powershell
powershell -ExecutionPolicy Bypass -File "demo/record_and_run.ps1"
```

此脚本会:
1. 启动 ffmpeg 后台录制桌面 (gdigrab，10fps，最长600秒)
2. 运行完整的三个功能点演示
3. 演示结束后自动停止录制
4. 生成 `output/demo_video.mp4`

### 方式二: 手动录制

```bash
# 先启动录制 (在单独的终端)
demo/record_demo.bat

# 然后在另一个终端运行演示
python demo/run_demo.py
```

### 视频参数

| 参数 | 值 |
|------|-----|
| 格式 | MP4 (H.264) |
| 帧率 | 10 fps |
| 编码 | libx264, preset=fast, CRF=24 |
| 像素格式 | yuv420p (最大兼容性) |
| 最长时长 | 10分钟 (600秒) |
| 录制范围 | 整个桌面 |

### 录制注意事项

1. 确保 ffmpeg 已安装并在系统 PATH 中 (验证: `ffmpeg -version`)
2. 录制前关闭不必要的应用程序窗口
3. 录制期间不要操作鼠标键盘，以免干扰演示
4. 建议使用1920×1080或更高分辨率屏幕以确保输出清晰
5. 如需录制特定窗口而非全屏，可修改ffmpeg参数中的 `-i desktop` 为 `-i title="窗口标题"`
